dependencies + package (editable)* and *Verify lockfile is up to date* —
closing Gate B with independently observable CI evidence.

## Lockfile maintenance

- Regenerate after changing `pyproject.toml` dependencies: `make lock`
  (runs `pip-compile --resolver=backtracking --extra=all --extra=dev
  --generate-hashes`).
- The CI drift check recomputes the lock and fails on any difference, so
  a stale lockfile blocks the build by design.
- Regeneration is deterministic apart from the header comment (verified
  locally: two consecutive runs produce identical content).
