# CI Lockfile Patch — Maintainer Application Guide

The Phase 6 changeset modifies `.github/workflows/ci.yml` to:

1. Install dependencies from `requirements.lock.txt` with
   `pip install --require-hashes` (Gate B — dependency reproducibility).
2. Verify the lockfile is up to date by recompiling and diffing.
3. Run the three new Phase 6 test files in the security-unit step.

The session's GitHub App token lacks `workflows:write` scope, so this
change was committed locally but cannot be pushed by the agent. A
maintainer should apply it after merging PR #6:

```bash
# From the repo root, on the main branch after merging PR #6:
git checkout main
git pull

# Apply the patch (also available in the PR working tree at
# .github/workflows/ci.yml on branch arena/01a00e9b-kerno — copy it
# directly if easier):
git show arena/01a00e9b-kerno:.github/workflows/ci.yml > .github/workflows/ci.yml

# Verify
git diff --stat
python -m pytest tests/unit/test_management_plane.py \
                 tests/unit/test_transport_parity.py \
                 tests/unit/test_static_gate.py -q

# Commit and push directly (or via a short PR)
git add .github/workflows/ci.yml
git commit -m "ci: pin deps via requirements.lock.txt and add Phase 6 tests (Gate B)"
git push origin main
```

repository is ready for the Gate G branch-protection settings described
